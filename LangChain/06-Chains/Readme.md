# Chains in LangChain

## What is a Chain?

A Chain is a composable sequence where the output of one step automatically becomes the input to the next step. Rather than implementing component connections manually:

* Prompt → LLM → Parse output
* Again prompt → LLM → Parse output
* Manually passing data between them

👉 **LangChain Chains do this wiring for you**

---

## 2️⃣ Why Do We Need Chains?

### ❌ Without Chains (Messy Code)

```python
text = llm1(prompt1.format(topic=topic))
summary = llm2(prompt2.format(text=text))
```

Problems:

* Manual wiring
* Hard to debug
* Hard to extend
* No visualization
* No reuse

---

### ✅ With Chains (Clean & Scalable)

```python
chain = prompt1 | llm1 | parser | prompt2 | llm2 | parser
```

Benefits:

* Automatic execution
* Clean flow
* Easy to debug
* Easy to visualize
* Production-ready pipelines

---

## 3️⃣ Core Building Blocks of a Chain

Every chain is built from **Runnables**.

| Component        | Role                     |
| ---------------- | ------------------------ |
| PromptTemplate   | Prepares input           |
| LLM / Chat Model | Generates response       |
| OutputParser     | Structures output        |
| Runnable         | Glue that connects steps |

👉 **Everything that can be executed = Runnable**

---

## 4️⃣ LangChain Expression Language (LCEL)

LCEL uses **pipe (`|`) syntax**.

Think like Unix pipes:

```bash
command1 | command2 | command3
```

Same idea in LangChain:

```python
prompt | model | parser
```

---

## 5️⃣ Sequential Chain (Most Common)

### 🔹 Concept

Steps run **one after another**.

```
Input → Step 1 → Step 2 → Step 3 → Output
```

---

### 🔹 Example Use Case

* Generate a report
* Then summarize it

---

### ✅ Code Example (Sequential Chain)

```python
from langchain.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from langchain.output_parsers import StrOutputParser

llm = ChatOpenAI(model="gpt-4o-mini")

report_prompt = PromptTemplate(
    template="Write a detailed report on {topic}",
    input_variables=["topic"]
)

summary_prompt = PromptTemplate(
    template="Summarize the following report in 5 bullet points:\n{report}",
    input_variables=["report"]
)

chain = (
    report_prompt
    | llm
    | StrOutputParser()
    | {"report": lambda x: x}
    | summary_prompt
    | llm
    | StrOutputParser()
)

output = chain.invoke({"topic": "Cricket"})
print(output)
```

---

### 🔹 Key Learning

* Each step **automatically passes output**
* No manual variable handling
* Very readable

---

## 6️⃣ Parallel Chain (Run Multiple Tasks Together)

### 🔹 Concept

Same input → **multiple chains run simultaneously**

```
{text}
   ↓
RunnableParallel
   ├── notes → OpenAI → parser
   └── quiz  → Claude → parser
   ↓
{
  notes: "...",
  quiz: "..."
}
   ↓
PromptTemplate (merge)
   ↓
OpenAI
   ↓
Final merged document

```

---

### 🔹 Example Use Case

From same content:

* Generate notes
* Generate quiz questions

---

### ✅ Code Example (parallel_chain | merge_chain)

```python
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic
from dotenv import load_dotenv
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain.schema.runnable import RunnableParallel

load_dotenv()

# Models
model1 = ChatOpenAI(model="gpt-4o-mini")
model2 = ChatAnthropic(model_name="claude-3-7-sonnet-20250219")

# Prompts
prompt1 = PromptTemplate(
    template="Generate short and simple notes from the following text:\n{text}",
    input_variables=["text"]
)

prompt2 = PromptTemplate(
    template="Generate 5 short question answers from the following text:\n{text}",
    input_variables=["text"]
)

prompt3 = PromptTemplate(
    template="""
      Merge the provided notes and quiz into a single well-structured document. \n NOTES: {notes} and QUIZ: {quiz}
    """,
    input_variables=["notes", "quiz"]
)

parser = StrOutputParser()

# Parallel execution
parallel_chain = RunnableParallel({
    "notes": prompt1 | model1 | parser,
    "quiz": prompt2 | model2 | parser
})

# Merge + final model
merge_chain = prompt3 | model1 | parser

# Full chain
chain = parallel_chain | merge_chain

# Invoke
result = chain.invoke({"text": text})
print(result)

# Visualize
chain.get_graph().print_ascii()
```

---

### 🔹 Why Parallel Chains Matter

* Faster execution
* Clean separation of tasks
* Ideal for dashboards, reports, assessments

## 7️⃣ Conditional Chain (If-Else Logic)

### 🔹 Concept

Execution path depends on a **structured condition** generated by an LLM.

```
User Feedback
     ↓
Sentiment Classification (Structured Output)
     ↓
IF positive  → Positive Response
IF negative  → Negative Response
ELSE         → Fallback
```

This pattern allows LLMs to **make decisions**, not just generate text.

---

### 🔹 Example Use Case

**Customer feedback automation system:**

* Positive feedback → Thank-you response
* Negative feedback → Support or apology response
* Unknown → Safe fallback

---

### ✅ Structured Output (Very Important)

To make conditional logic reliable, we **force the LLM to return structured output** using Pydantic.

```python
from pydantic import BaseModel, Field
from typing import Literal
from langchain_core.output_parsers import PydanticOutputParser

class Feedback(BaseModel):
    sentiment: Literal["positive", "negative"] = Field(
        description="Sentiment of the feedback"
    )

parser = PydanticOutputParser(pydantic_object=Feedback)
```

✅ This guarantees:

* No hallucinated labels
* Safe branching
* Deterministic workflows

---

### ✅ Conditional Chain Code (RunnableBranch)

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain.schema.runnable import RunnableBranch, RunnableLambda

llm = ChatOpenAI()
string_parser = StrOutputParser()

# 1. Sentiment classification prompt
sentiment_prompt = PromptTemplate(
    template="""
Classify the sentiment of the following feedback into positive or negative.

Feedback:
{feedback}

{format_instruction}
""",
    input_variables=["feedback"],
    partial_variables={
        "format_instruction": parser.get_format_instructions()
    }
)

# 2. Classification chain (returns Pydantic object)
classifier_chain = sentiment_prompt | llm | parser

# 3. Response prompts
positive_prompt = PromptTemplate(
    template="Write an appropriate response to this positive feedback:\n{feedback}",
    input_variables=["feedback"]
)

negative_prompt = PromptTemplate(
    template="Write an appropriate response to this negative feedback:\n{feedback}",
    input_variables=["feedback"]
)

# 4. Conditional branching
branch_chain = RunnableBranch(
    (lambda x: x.sentiment == "positive", positive_prompt | llm | string_parser),
    (lambda x: x.sentiment == "negative", negative_prompt | llm | string_parser),
    RunnableLambda(lambda x: "Could not determine sentiment.")
)

# 5. Final chain
final_chain = classifier_chain | branch_chain

# Invoke
print(final_chain.invoke({"feedback": "This is a beautiful phone"}))
```

---

### 🔹 Why Conditional Chains Are Powerful

* Enables **decision-making AI**
* Safe and predictable control flow
* Ideal for **customer support, moderation, routing**
* Foundation for **agents and autonomous workflows**
