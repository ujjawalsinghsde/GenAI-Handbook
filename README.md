# GenAI Handbook

This repository provides a structured and comprehensive collection of materials for learning and implementing modern Generative AI systems.  
It covers AWS GenAI services, LangChain, LangGraph, Retrieval-Augmented Generation (RAG), and agent-based workflows used in real-world applications.

The modules are designed for developers and engineers who want to build reliable, scalable, and production-ready GenAI solutions.

---

## Generative AI (GenAI)

Generative AI enables systems to produce new content—such as text, code, summaries, analysis, and reasoning outputs—based on patterns learned from large-scale datasets.  
This repository includes practical material that demonstrates how these capabilities can be used in enterprise and product environments.

---

## Large Language Models (LLMs)

Large Language Models are central to modern GenAI applications.  
This repository provides guidance on:

- LLM fundamentals  
- Model invocation patterns  
- Prompt engineering  
- Structured outputs  
- Multimodal inputs  
- Integration with AWS Bedrock and other providers  

---

## LangChain

LangChain provides the building blocks for developing GenAI systems.  
This section includes detailed modules on:

- Models and prompting  
- Structured output and parsers  
- Runnables and chains  
- Document loading and text splitting  
- Vector stores and retrievers  
- RAG workflows  
- Tool execution and function calling  

The content is organized to support both foundational learning and applied system design.

---

## LangGraph (Agentic AI)

LangGraph extends LangChain by introducing a graph-based, stateful execution framework that is suited for advanced agentic workloads.

This section focuses on:

- Building controllable AI agents  
- Constructing iterative reasoning loops  
- Managing tool use and state transitions  
- Designing reliable, fault-tolerant workflows  
- Multi-step orchestration and planning  

This will be added as a dedicated module in line with the rest of the repository.

---

## Repository Structure

The repository is organized into modular sections:

- **AWS-GenAI** — Bedrock, Nova, RAG workflows, embeddings, and AWS-specific GenAI components  
- **LangChain** — Complete learning path for using LangChain effectively  
- **LangGraph** (upcoming) — Agentic workflows and graph-based reasoning  
- Additional utilities, examples, and notes added over time  

Each section contains independent modules that can be studied standalone or as part of the full GenAI learning path.
